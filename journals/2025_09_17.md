- 稳态通量公式
  collapsed:: true
	- 下面把“溶解–扩散模型”的**稳态通量公式**从零基础讲清楚，并给出常用写法与每个符号的意思。
	- # 1) 这类膜传质是怎么发生的？
	  
	  把致密膜想成一块均匀的“海绵胶”，孔很小（其实可看作**无孔**），溶质要过膜会经历三步：
	- **在进料侧溶解进膜**（界面处分配/溶解），
	- **在膜内靠浓度梯度扩散**，
	- **在渗透侧从膜里跑出来**（再次分配/解吸）。
	- # 2) 膜内扩散：Fick 第一定律
	  
	  在膜内部，一维稳态（浓度不随时间变）时，通量 JJ 由 Fick 定律给出：
	  
	  J=−D dCmdxJ = -D\,\frac{dC_m}{dx}
	- JJ：通量，单位常用 mol m−2 s−1\text{mol}\,\text{m}^{-2}\,\text{s}^{-1}
	- DD：膜内扩散系数，m2/s\text{m}^2/\text{s}
	- Cm(x)C_m(x)：膜内浓度（注意是**膜相**浓度）
	- xx：沿膜厚方向坐标
	  
	  稳态且 DD 取常数时，膜内浓度是**线性**的。把膜厚记为 ll，积分得到：
	  
	  J  =  Dl (Cm,1−Cm,2)J \;=\; \frac{D}{l}\,\big(C_{m,1}-C_{m,2}\big)
	  
	  这里 Cm,1C_{m,1} 和 Cm,2C_{m,2} 分别是膜**进料侧界面**与**渗透侧界面**的膜相浓度。
	- # 3) 界面分配（溶解/解吸）
	  
	  界面上，溶质在“外部相”和“膜相”之间达到**分配平衡**：
	  
	  Cm,1=K C1,Cm,2=K C2C_{m,1}=K\,C_1,\qquad C_{m,2}=K\,C_2
	- C1,C2C_1, C_2：膜两侧外部相的溶质“驱动力变量”（最常用是**浓度**；气体常用**分压 pp**）
	- KK：分配系数（外相→膜相的溶解度/亲和力）。
	  
	  对气体也常写作溶解度 SS（亨利定律：Cm=S pC_m=S\,p）。
	  
	  把分配关系代入上式：
	  
	  J  =  Dl (KC1−KC2)  =  DKl (C1−C2)J \;=\; \frac{D}{l}\,\big(KC_1 - KC_2\big)
	  \;=\; \frac{DK}{l}\,(C_1 - C_2)
	- # 4) 经典的“渗透率”形式
	  
	  把 P≡DKP \equiv D K 定义为**渗透系数（permeability）**，得到最常用的稳态通量公式：
	  
	  J  =  Pl ΔC (ΔC=C1−C2)\boxed{\,J \;=\; \dfrac{P}{l}\,\Delta C \,}\qquad
	  \big(\Delta C = C_1 - C_2\big)
	- **液体/溶液体系**（以浓度作驱动力）：
	  
	  J=DKl (C1−C2)J=\frac{D K}{l}\,(C_1-C_2)
	- **气体膜分离**（以分压作驱动力，Cm=S pC_m=S\,p）：
	  
	  J=DSl (p1−p2)  =  Pl Δp \boxed{\,J=\frac{D S}{l}\,(p_1-p_2) \;=\; \frac{P}{l}\,\Delta p\,}
	  
	  此时 P=DSP=DS；工程上常用 **Barrer** 等单位表示 PP。
	- # 5) 物理图像与要点
	- **线性浓度剖面**：稳态、DD 常数 → 膜内 Cm(x)C_m(x) 是直线。
	- **三步走**：分配（进膜）→ 扩散（膜内）→ 分配（出膜）。
	- **厚度越厚、通量越小**：J∝1/lJ \propto 1/l。
	- **膜材料越“亲”溶质（KK 大）或扩散越快（DD 大），通量越大**。
	- **边界条件**来自界面分配，而不是把外部浓度直接塞进 Fick 定律。
	- # 6) 一个小示例（溶液体系）
	- l=100 μm=1×10−4 ml=100\,\mu\text{m}=1\times10^{-4}\,\text{m}
	- D=1×10−10 m2/sD=1\times10^{-10}\,\text{m}^2/\text{s}
	- K=2K=2
	- C1=1.0 mol/m3,  C2≈0C_1=1.0\,\text{mol}/\text{m}^3,\; C_2\approx0
	  
	  则
	  
	  J=DKl(C1−C2)=(1×10−10)×21×10−4×1.0=2×10−6  mol m−2 s−1.J=\frac{D K}{l}(C_1-C_2)
	  =\frac{(1\times10^{-10})\times 2}{1\times10^{-4}}\times 1.0
	  =2\times10^{-6}\;\text{mol}\,\text{m}^{-2}\,\text{s}^{-1}.
	- # 7) 何时需要更复杂的公式？
	  
	  若存在 **非稳态、DD 随浓度变、膜内有反应、强耦合溶剂化/体积排斥、界面极化** 等，简单的线性关系会失效，需要更完整的模型。但在许多致密膜的基础分析里，上述**稳态通量**就是起点。

- m-s方程
  collapsed:: true
	- 好嘞！接着上文，从“致密膜的溶解–扩散”过渡到**多孔膜**里的 **Maxwell–Stefan（M–S）方程**。核心直觉：
	  
	  > 
	  
	  **驱动力 = 各种“摩擦/阻力”的平衡**。
	  
	  在混合物里，组分 ii 被谁“拽住”？——被其它组分 jj（分子–分子碰撞）和**孔壁**（分子–壁碰撞，Knudsen）拽住；还有压差会把整个流体“推着走”（黏性/达西流）。
	  
	  ---
	- # 1) 自由流体中的 Maxwell–Stefan（温度、总压不变的简化形态）
	  
	  用“**摩尔扩散通量**”Ji\mathbf{J}_i（相对于混合物摩尔平均速度）写，且满足 ∑iJi=0\sum_i \mathbf{J}_i=0：
	  
	  −∇ln⁡ai=∑j≠ixj Ji−xi Jjc D~ij-\nabla \ln a_i
	  =\sum_{j\ne i}\frac{x_j\,\mathbf{J}_i - x_i\,\mathbf{J}_j}{c\,\tilde D_{ij}}
	- aia_i：活度（理想气体/稀溶液可用 ai≈xia_i\approx x_i）；
	- xix_i：摩尔分数，cc：总摩尔浓度；
	- D~ij\tilde D_{ij}：**Maxwell–Stefan 扩散系数**（成对“摩擦系数”的倒数，量纲 m²/s）。
	  
	  这比 Fick 定律更“底层”，因为它天然包含**多组分耦合**：Ji\mathbf{J}_i 不只由 ∇xi\nabla x_i 决定，还受别的 Jj\mathbf{J}_j 影响。
	  
	  ---
	- # 2) 放进“多孔介质”的三件事
	  
	  多孔膜里通道弯弯绕绕、面积被孔隙打折，还多了**孔壁摩擦**。常见做法：
	- ### (a) 孔隙率–曲折度修正（几何效应）
	  
	  把双组分 M–S 系数“等效化”：
	  
	  D~ij,eff=ετ D~ij\tilde D_{ij,\mathrm{eff}}=\frac{\varepsilon}{\tau}\,\tilde D_{ij}
	- ε\varepsilon：孔隙率；τ\tau：曲折度（τ≥1\tau\ge 1）。
	  
	  直觉：有效扩散系数被“通道更窄更曲折”削弱。
	- ### (b) 孔壁摩擦（Knudsen 扩散）
	  
	  分子和孔壁碰撞产生**额外阻力**，在 M–S 里表现为**对壁**的一项：
	  
	  −∇ln⁡ai=∑j≠ixj Ji−xi Jjc D~ij,eff  +  Jic D~iK,eff-\nabla \ln a_i
	  =\sum_{j\ne i}\frac{x_j\,\mathbf{J}_i - x_i\,\mathbf{J}_j}{c\,\tilde D_{ij,\mathrm{eff}}}
	  \;+\; \frac{\mathbf{J}_i}{c\,\tilde D_{iK,\mathrm{eff}}}
	  
	  这里 D~iK\tilde D_{iK} 是 **Knudsen 扩散系数**（仅由孔径与分子量定标）：
	  
	  D~iK=23 rp8RTπMi,D~iK,eff=ετ D~iK\tilde D_{iK}=\frac{2}{3}\,r_p\sqrt{\frac{8RT}{\pi M_i}},\qquad
	  \tilde D_{iK,\mathrm{eff}}=\frac{\varepsilon}{\tau}\,\tilde D_{iK}
	- rpr_p：特征孔半径；MiM_i：相对分子质量；R,TR,T：气体常数与温度。
	  
	  当孔很细（均值自由程 λ≫rp\lambda\gg r_p）时，**Knudsen 主导**。
	- ### (c) 压差驱动的体积流（黏性/达西流）
	  
	  总摩尔通量 = 扩散 + 被“水流”带走：
	  
	  Ni=Ji+xi c u,u=−Bμ ∇p\mathbf{N}_i=\mathbf{J}_i + x_i\,c\,\mathbf{u},
	  \qquad
	  \mathbf{u} = -\frac{B}{\mu}\,\nabla p
	- u\mathbf{u}：表观（达西）速度；μ\mu：黏度；BB：多孔介质渗透率。
	  
	  这就是把**达西定律**叠加到 M–S 的框架里——常被称为**Dusty-Gas Model（DGM，含壁项的 M–S）**。
	  
	  ---
	- # 3) 常见极限与和 Fick 的关系
	- **宽孔/低 Knudsen（Kn=λ/rp≪1Kn=\lambda/r_p\ll 1**）：
	  
	  孔壁项可忽略，M–S 退化为“几何修正的自由扩散”，二元等摩反扩（NA=−NB, u=0N_A=-N_B,\ \mathbf{u}=0）下得到
	  
	  JA=− c ετ DAB ∇xAJ_A = -\,c\,\frac{\varepsilon}{\tau}\,D_{AB}\,\nabla x_A
	  
	  也就是 Fick 定律（只是把 DABD_{AB} 改成了 (ε/τ)DAB(\varepsilon/\tau)D_{AB}）。
	- **细孔/Knudsen 主导（Kn≫1Kn\gg1**, 且二元等摩反扩）：
	  
	  JA=− c ετ DK,A ∇xAJ_A = -\,c\,\frac{\varepsilon}{\tau}\,D_{K,A}\,\nabla x_A
	- **稀释组分 A 在惰性 B 中扩散（NB≈0N_B\approx 0**，常见于痕量气体透过膜）：
	  
	  扩散阻力可视为**串联**，得到著名的 **Bosanquet 公式**：
	  
	  1DA,eff=1(ε/τ) DAB+1(ε/τ) DK,A  ⇒JA=− c DA,eff ∇xA\boxed{\;
	  \frac{1}{D_{A,\mathrm{eff}}}
	  = \frac{1}{(\varepsilon/\tau)\,D_{AB}}
	  + \frac{1}{(\varepsilon/\tau)\,D_{K,A}}
	  \;}
	  \quad\Rightarrow\quad
	  J_A = -\,c\,D_{A,\mathrm{eff}}\,\nabla x_A
	  
	  直觉：A 既要“躲 B”（分子–分子摩擦），又要“躲墙”（分子–壁摩擦）。
	- **有压差（∇p≠0\nabla p\neq 0**）时：
	  
	  还会叠加一个对流通量 xicux_i c \mathbf{u}（黏性渗流），导致**扩散+对流耦合**；对于气体分离膜，这就是为什么高压差下会看到“扫气效应/稀释效应”。
	  
	  ---
	- # 4) 用 M–S/DGM 解题的一般步骤（1D 稳态）
	- 选驱动力（常用等温理想、∇ln⁡ai≈∇ln⁡xi\nabla\ln a_i\approx \nabla\ln x_i）。
	- 列出每个 ii 的 M–S 方程（含壁项），再加上 ∑iJi=0\sum_i \mathbf{J}_i=0。
	- 若有压差，加上达西速度 u\mathbf{u}，把 Ni=Ji+xicu\mathbf{N}_i=\mathbf{J}_i+x_i c \mathbf{u} 代入边界条件。
	- 用 D~ij,eff=(ε/τ)D~ij\tilde D_{ij,\mathrm{eff}}=(\varepsilon/\tau)\tilde D_{ij}、D~iK,eff=(ε/τ)D~iK\tilde D_{iK,\mathrm{eff}}=(\varepsilon/\tau)\tilde D_{iK}。
	- 形成线性方程组求 Ji\mathbf{J}_i（或 Ni\mathbf{N}_i），再按膜厚 ll 把梯度用 Δ(⋅)/l\Delta(\cdot)/l 近似求通量。
	  
	  ---
	- # 5) 什么时候必须用 M–S（而不是 Fick）？
	- **多组分（≥3）**，相互“牵制”明显；
	- **浓度差大**或**强对流耦合**（有压差/扫气）；
	- **细孔**（Knudsen 显著）；
	- 存在**不可忽略的惰性/滞留组分**（例如载气不流动、NB≈0N_B\approx 0）——此时 Fick 易误差很大。
	  
	  ---
	- # 6) 小结（一句话版）
	  
	  **Maxwell–Stefan**把“化学势/活度梯度”当驱动力，把“与其它组分的摩擦 + 与孔壁的摩擦 + 压差导致的整体拖拽”当阻力；
	  
	  在多孔膜里，只要把扩散系数做**ε/τ 修正**、加上**Knudsen 壁项**，并考虑**达西对流**，就得到了工程上常用的 **Dusty-Gas 模型**。
	  
	  在特定极限（宽孔或细孔、稀释或等摩反扩）才会简化回熟悉的 Fick 形式。
